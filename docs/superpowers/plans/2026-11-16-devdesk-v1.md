# DevDesk 第一版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付可在 Windows 本机发现运行环境与服务、安全管理已登记实例、修改 MySQL/Redis Windows 服务端口，并保留日志及操作历史的桌面应用。

**Architecture:** Tauri 2 承载桌面窗口和受限命令接口，Vue 3 展示总览与详情，Rust 独占系统访问、进程管理、配置修改和 SQLite。先做只读发现与登记，再加入 Windows 服务操作和端口切换，最后加入手动程序、日志与跨会话接管；每一阶段都有可独立验证的可运行界面。

**Tech Stack:** Tauri 2、Vue 3、TypeScript、Rust、SQLite（`rusqlite`）、Windows SCM/进程/端口 API（`windows` crate）、`uuid`、Vitest。首次初始化时固定依赖版本并生成锁文件；本计划不预设未验证的具体包版本。

**Spec:** [第一版设计稿](../specs/2026-11-16-devdesk-v1-design.md)

## Global Constraints

- 目标为 Windows 10/11 x64 本机应用，第一条真实验收链使用当前机器的 MySQL80、Redis；对真实服务的写操作需要用户届时明确决定。
- 主程序普通权限运行；需管理员权限的单次操作使用短时受限提权进程。未知进程和身份无法核对的外部进程只读。
- 端口占用时只展示可获得的进程证据并阻止修改；不自动结束进程。停止中的服务改端口后维持停止。
- 配置修改前备份；失败保留现场并提供恢复入口。操作历史不得保存密码或完整环境变量。
- 关闭 DevDesk 后已启动的程序继续运行、输出持续落盘；再次打开先核对实际进程身份再恢复管理。
- 所有新增或修改的人工编写 Java 方法须有中文 JavaDoc；本路线没有计划编写 Java 生产代码。
- 当前目录已初始化 Git 仓库。提交和推送仍须分别获得用户明确授权；仅本次新建的生产业务代码在必要测试与差异检查后按具体路径暂存，测试、配置和文档不自动暂存。

## Review Focus

- 同类软件有多个服务实例：测试只操作指定服务名，列表不合并实例。
- 服务显示 Running 但端口未监听：测试分别显示服务状态与端口状态，不声称可用。
- 新端口被 IPv4 或 IPv6 进程占用：测试阻止修改并展示 PID；进程详情不可读时标记未知。
- 启动脚本退出而 Java 子进程仍在：测试不把脚本 PID 当服务身份；无法核对时停止按钮禁用。
- DevDesk 退出后程序继续输出：测试重开后日志无断档，并检查日志和操作历史不泄露敏感值。

## File Map

- `src-tauri/src/model.rs`：服务实例、候选、状态、端口与操作结果的序列化类型。
- `src-tauri/src/store.rs`：SQLite 初始化、登记信息及操作历史读写。
- `src-tauri/src/discovery.rs`：SCM、环境变量、PATH、指定目录和当前进程的只读扫描。
- `src-tauri/src/ports.rs`：IPv4/IPv6 监听端口到 PID 的只读查询。
- `src-tauri/src/service.rs`：Windows 服务状态读取与具体实例的启停编排。
- `src-tauri/src/config.rs`：MySQL/Redis 已知配置字段解析、备份、修改与恢复。
- `src-tauri/src/manual.rs`：手动命令程序、脚本、实际子进程身份与跨会话接管。
- `src-tauri/src/logs.rs`：持久输出重定向与增量日志读取。
- `src-tauri/src/lib.rs`：Tauri 命令注册与后台任务；不容纳业务解析逻辑。
- `src-tauri/src/bin/devdesk-helper.rs`：需 UAC 的有限 Windows 服务及配置操作；不接受任意 shell 命令。
- `src/types.ts`：与 Rust 序列化契约一致的前端类型。
- `src/api.ts`：前端对 Tauri 命令和事件的唯一调用入口。
- `src/App.vue`、`src/components/ServiceList.vue`、`src/components/ServiceDetail.vue`、`src/components/CandidateList.vue`：总览、详情和待确认区域。
- `src/components/InstanceForm.vue`、`src/components/SettingsPanel.vue`：实例登记与指定扫描目录。
- `src/components/LogView.vue`、`src/components/OperationHistory.vue`：增量日志与本地操作记录。
- `src-tauri/tests/*.rs`、`src/**/*.test.ts`：使用隔离文件、假服务适配器和测试进程验证行为；不得写入真实服务。
